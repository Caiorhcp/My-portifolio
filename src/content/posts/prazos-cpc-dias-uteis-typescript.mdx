"No prazo de 15 (quinze) dias." Toda peça processual tem uma frase assim, e quem trabalha com processo sabe que contar esses dias no calendário dá trabalho. No [S.A.P.O.](/projetos/sapo), o sistema encontra o prazo no texto e calcula o vencimento sozinho. Este post mostra as regras e como elas viraram código.

## As três regras do CPC

O Código de Processo Civil define o jogo em três artigos:

- **Art. 219:** prazos em dias contam apenas os **dias úteis**.
- **Art. 220:** o curso dos prazos fica suspenso de **20 de dezembro a 20 de janeiro**, o recesso forense.
- **Art. 224:** exclui-se o dia do começo e inclui-se o do vencimento. Se o vencimento cair em dia sem expediente, ele passa para o próximo dia útil.

Na prática: a contagem começa no dia seguinte à intimação e só anda nos dias úteis.

## Encontrando o prazo no texto

Antes de calcular, é preciso achar o prazo. Uma expressão regular procura padrões como "prazo de", "em até" ou "dentro de", seguidos de um número e de uma unidade. O número pode vir em algarismos ou por extenso, e o extenso entre parênteses é ignorado:

- "no prazo de 15 (quinze) dias" → 15 dias úteis;
- "em até 48 horas" → horas (não dá para calcular sem a hora exata da intimação);
- "prazo de 30 dias corridos" → 30 dias corridos.

## Datas sem fuso horário

O primeiro bug clássico de calendário em JavaScript é o fuso. `new Date(2026, 0, 1)` usa o fuso do navegador, e dependendo de onde a pessoa está o dia "muda". A solução foi trabalhar sempre em UTC:

```ts
const day = (y: number, m: number, d: number) => new Date(Date.UTC(y, m - 1, d));
const addDays = (date: Date, n: number) => new Date(date.getTime() + n * 86_400_000);
```

## Feriados que mudam todo ano

Os feriados nacionais fixos são fáceis: 1º de janeiro, 21 de abril, 1º de maio, 7 de setembro, 12 de outubro, 2 e 15 de novembro, 25 de dezembro e, desde a Lei 14.759/2023, 20 de novembro.

Os móveis dependem da Páscoa. Carnaval cai 47 dias antes dela, a Sexta-feira Santa 2 dias antes e Corpus Christi 60 dias depois. Para a Páscoa existe um algoritmo antigo e exato, o de Meeus/Jones/Butcher, que cabe em poucas linhas de aritmética inteira:

```ts
export function easter(y: number): Date {
  const a = y % 19, b = Math.floor(y / 100), c = y % 100, d = Math.floor(b / 4), e = b % 4;
  const f = Math.floor((b + 8) / 25), g = Math.floor((b - f + 1) / 3), h = (19 * a + b - d - g + 15) % 30;
  const i = Math.floor(c / 4), k = c % 4, l = (32 + 2 * e + 2 * i - h - k) % 7, m = Math.floor((a + 11 * h + 22 * l) / 451);
  const month = Math.floor((h + l - 7 * m + 114) / 31), dayOfMonth = ((h + l - 7 * m + 114) % 31) + 1;
  return day(y, month, dayOfMonth);
}
```

## O que é um dia útil

Juntando tudo, um dia é útil se não for sábado nem domingo, não for feriado e não estiver no recesso:

```ts
const inRecess = (d: Date) => {
  const m = d.getUTCMonth() + 1, dd = d.getUTCDate();
  return (m === 12 && dd >= 20) || (m === 1 && dd <= 20);
};

export function isBusinessDay(d: Date): boolean {
  const w = d.getUTCDay();
  return w !== 0 && w !== 6 && !holidays(d.getUTCFullYear()).has(key(d)) && !inRecess(d);
}
```

## O vencimento

Com isso, o cálculo é um laço: anda um dia por vez a partir da intimação e só desconta os dias úteis.

```ts
for (let left = prazo; left > 0; ) {
  date = addDays(date, 1);
  if (isBusinessDay(date)) left--;
}
```

Para prazos em dias corridos, meses ou anos, soma-se direto e, se o último dia cair sem expediente, empurra-se para o próximo dia útil, como manda o art. 224.

## Os limites, ditos em voz alta

Uma ferramenta de prazo que erra em silêncio é perigosa. Por isso o S.A.P.O. avisa o que **não** considera:

- feriados estaduais e municipais e os dias sem expediente de cada tribunal;
- regras especiais de início de prazo do art. 231 do CPC (por exemplo, intimação eletrônica ou por edital);
- prazos em dobro, como os da Fazenda Pública e da Defensoria.

O cálculo ajuda na triagem, mas não substitui a conferência de quem assina a peça. Esse aviso está na própria tela, ao lado do resultado.

## Testes, sempre

Calendário é o tipo de código que parece certo até o dia em que não está. Os testes cobrem a data da Páscoa, os dias sem expediente, um prazo de 15 dias úteis que atravessa fim de semana e feriado, um prazo suspenso pelo recesso, dias corridos com vencimento prorrogado e prazos em horas, que ficam sem data calculada.
